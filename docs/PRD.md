# PRD.md - 반도체 시료 생산주문관리 시스템

## 배경 및 목적

가상의 반도체 회사 "S-Semi"는 연구소, 팹리스 업체, 대학 연구실 등에 반도체 시료를 납품합니다.
주문량 급증으로 엑셀·메모장 기반 관리의 한계가 발생하여 체계적인 관리 시스템이 필요합니다.

## 사용자 역할

| 역할 | 행동 |
|------|------|
| 고객 | 필요한 시료를 이메일로 요청 |
| 주문 담당자 | 요청에 맞게 주문서 작성 및 관리 |
| 생산 담당자 | 시료 등록, 주문 수신 후 승인 또는 거절 |

## 기능 요구사항

### 1. 시료 관리

- **시료 등록**: 시료 ID, 이름, 평균 생산시간, 수율, 초기 재고 입력
- **시료 조회**: 등록된 전체 시료 목록 + 현재 재고 수량 표시
- **시료 검색**: 이름 등 속성으로 검색

### 2. 시료 주문 (접수)

- 입력: 시료 ID, 고객명, 주문 수량
- 접수 즉시 RESERVED 상태
- 주문번호 자동 생성: `ORD-YYYYMMDD-NNNN`

### 3. 주문 승인/거절

- RESERVED 주문 목록 표시
- **승인 로직**:
  - 재고 ≥ 주문 수량 → CONFIRMED (출고 대기)
  - 재고 < 주문 수량 → PRODUCING (생산 라인 자동 등록)
- **거절**: REJECTED 상태로 즉시 전환

### 4. 모니터링

- 상태별 주문 건수 (RESERVED / PRODUCING / CONFIRMED / RELEASE)
- 시료별 재고 현황 및 상태 (여유 / 부족 / 고갈)

### 5. 생산라인

- 현재 생산 중인 시료 정보 (주문번호, 시료명, 주문량, 실생산량, 생산시간(min))
- 대기 중인 생산 큐 목록 (FIFO 순서)
- 생산 완료 시 PRODUCING → CONFIRMED 자동 전환

### 6. 출고 처리

- CONFIRMED 주문 목록 표시
- 선택한 주문 출고 실행 → RELEASE 전환

## 비기능 요구사항

- 콘솔 기반 CLI 인터페이스
- 파이프 구분 텍스트 파일 기반 데이터 영속성 (`.dat`, 형식: `field1|field2|...`)
- 애플리케이션 재시작 후 데이터 유지

## 주문 상태 정의

| 상태 | 설명 |
|------|------|
| RESERVED | 주문 접수 완료 |
| REJECTED | 주문 거절 (모니터링 제외) |
| PRODUCING | 승인 완료, 재고 부족으로 생산 중 |
| CONFIRMED | 승인 완료, 출고 대기 중 |
| RELEASE | 출고 완료 |

## 생산 수량 공식

```
실 생산량 = ceil(부족분 / (수율 × 0.9))
총 생산 시간 = 평균 생산시간 × 실 생산량
```
